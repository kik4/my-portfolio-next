# セルルック3D 目配置検証ツール - 企画書

## 背景と目的

3Dセルルックキャラクターの顔は、目・眉が3Dメッシュに固定されているため、カメラ角度によって2Dイラスト/アニメと乖離する。特に以下の問題がある：

- 正面は良くても3/4アングルで目の配置が不自然になる
- 現状の業界の解決策は「正面を完璧にして横顔は髪で隠す」という割り切り
- 横顔の美しさ（特に男性キャラのイケメンさ）は未開拓領域

**仮説：** 目と眉を3Dメッシュから切り離し、カメラ角度に応じてスクリーン上での配置を動的に変えることで、正面から横顔まで全角度で「気持ちいい顔」を実現できるのではないか。

## ツール概要

Webブラウザ上で動作する検証ツール。3Dの頭モデル上で、目と眉の配置をリアルタイムに調整し、カメラを回しながら見栄えを確認する。

## 技術スタック

- Three.js（3Dレンダリング）
- React + TypeScript（UI）
- glTFモデル読み込み

## 必要なもの

### 3Dモデル（別途用意）
- VRoidで作成した頭モデル（VRM → Blender → glTF変換）
- 目と眉はBlenderで削除済み、またはマテリアルで非表示
- 鼻・口・髪はモデルに含まれる

### ツールが提供する機能

#### 1. シーン
- 頭モデルを中央に配置
- OrbitControlsでカメラをぐるぐる回せる
- セルルック風のシンプルなライティング（Unlitまたは2段階陰影）
- 背景はニュートラルグレー

#### 2. 目と眉の表示
- 目と眉はテクスチャ付きのPlane（2Dスプライト）として顔の前面に配置
- 顔メッシュのジオメトリには依存しない
- 左右の目、左右の眉で計4つのスプライト

#### 3. 手動調整パラメータ（UIスライダー）

目の配置：
- 水平位置（左右にスライド）
- 垂直位置（上下にスライド）
- 左右の目の間隔
- 目のサイズ（スケール）
- 目の回転（傾き）

眉の配置：
- 水平位置
- 垂直位置
- 眉の間隔
- 眉の回転

#### 4. カメラ角度連動（自動オフセット）
- カメラの水平角度（0°=正面、90°=横顔）を取得
- ON/OFFトグルで切り替え可能
- ONのとき、手動パラメータに加えて角度に応じたオフセットが加算される
- オフセットのカーブは後で調整（最初は線形で十分）

自動オフセットで制御するパラメータ：
- 目の水平位置（3/4で奥の目を中央寄りに）
- 目のサイズ（横顔に近づくほど小さく）
- 目の間隔（角度で変化）

#### 5. 検証ワークフロー
1. 自動オフセットOFFで、特定の角度にカメラを固定
2. 手動スライダーで「この角度で気持ちいい目の位置」を探る
3. 複数の角度（正面、30°、45°、60°、75°）で繰り返す
4. 各角度のベストな値を記録
5. それらの値を補間するカーブを自動オフセットとして設定
6. 自動オフセットONでカメラを回して、全角度で自然に見えるか確認

#### 6. あると良い機能（優先度低）
- 角度ごとのパラメータをプリセットとして保存・読み込み
- カメラ角度に応じたオフセットカーブのグラフ表示
- スクリーンショット撮影
- 目と眉のテクスチャを差し替え可能

## 制約・方針

- 画角（FOV）は固定（60〜70°）。画角は変数に含めない
- 対応角度は正面〜横顔（0°〜90°）。真後ろは対象外
- 最初はセルルックシェーダー不要。見栄えの検証が目的だから、目の位置が分かればいい
- モデルが無い段階ではプリミティブ（球体）で代用しても可
