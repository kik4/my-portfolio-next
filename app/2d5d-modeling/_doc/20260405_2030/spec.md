# 2D顔 × 3Dボディ アニメ表現ツール - 企画書

## 目的

スクリーンスペース2D描画で顔のパーツをルールベース変形させ、アニメらしい「2Dの嘘」を保ったまま3Dボディ・髪と合成する。

既存実装（ベジェ曲線＋キーフレーム補間）の課題を踏まえ、以下の方針で作り直す。

## 基本方針

### 描画方式
- 顔は **正射影 + スクリーンスペース** で描画
- 身体と髪は **3D（透視投影）**
- 顔のスクリーン上の表示位置は、3D頭部の原点をカメラで投影した座標
- 顔のサイズは、カメラと頭部の距離ベースでスケーリング

### ヨー/ピッチの分離処理
- **ヨー（左右）**: パーツごとのキーフレーム補間で形状を変化させる
- **ピッチ（上下）**: 顔面を平面のまま回転させる（形状は変えない）
- 回転中心は頭部の中心
- 3D髪・頭モデルは顔のヨー/ピッチに追従させる（幾何学的な正しさより顔との一致感を優先）

### 曲線表現
- ベジェ曲線をやめ、**点列 + Catmull-Rom** による細分割曲線を使う
- 制御点は位置のみ。ハンドルは不要

## データ構造

### パーツの再設計

鼻を3つの役割に分解：

| パーツ | 種類 | 役割 |
|---|---|---|
| 顔の輪郭 | 閉じた点列 | 頭・鼻・顎のシルエット |
| 鼻筋線 | 開いた点列 | 輪郭内側の線 |
| 遮蔽マスク | 閉じた点列（肌色塗り） | 奥の目をヨー時にクリップ |
| 目の形状 | 開いた点列 | 目の曲線そのもの（左右共通） |
| 目の位置・傾き・サイズ | (x, y, rotation, scale) | 左右個別 |

目は「形状」と「位置/傾き/サイズ」を分離することで、形状を共通化しつつ左右の配置をルールで制御できる。

### キーフレーム

- ヨー軸のみ（例: 0°, 30°, 60°, 90°）
- 各キーフレームに全パーツの点列と目の位置パラメータを保存
- RBF補間（既存の仕組みを流用・簡略化）

### Keyframe 型

```ts
interface Keyframe {
  yaw: number; // 水平角度（度）
  parts: {
    faceOutline: Point2D[];
    noseBridge: Point2D[];
    noseMask: Point2D[];
    eyeShape: Point2D[]; // 左右共通の曲線形状
  };
  leftEye: EyeTransform;
  rightEye: EyeTransform;
}

interface EyeTransform {
  position: Point2D;
  rotation: number; // 度
  scale: number;
}
```

## 描画フロー

### 1. 3Dシーン
- `base2.glb` の頭モデル（参考表示用、opacity調整可）
- カメラはOrbitControls操作可能

### 2. 顔の配置
1. 3D頭部の原点（例: (0, 0, 0.1) などの固定点）をカメラで投影してスクリーン座標を得る
2. 顔のサイズ = `baseSize * (baseDistance / cameraDistance)` でスケール
3. 現在のカメラヨー角度を取得し、RBF補間でキーフレームを生成
4. SVGでパーツを描画：
   - 顔輪郭（塗り + 線）
   - 遮蔽マスク（肌色塗り、目の上に重ねる）
   - 左右の目（形状 × 位置/傾き/サイズ）
   - 鼻筋線
5. SVG全体を `transform: rotate(pitch) translate(x, y) scale(s)` で配置

### 3. ピッチ回転
- カメラのピッチ角度をSVGの`rotate`に直接適用
- 回転中心は顔の中心（SVGのviewBox中心）

### 4. 3D髪の追従
- 3D頭モデルの回転量を、カメラ角度より減衰させる
- 例: `modelYaw = cameraYaw * 0.5` のように調整可能にする

## 最小構成（Phase 1）

1. 点列 + Catmull-Rom 描画（BezierEditorを点列版に書き換え）
2. パーツ再構成（4種 + 目の形状 + 目の変換）
3. ヨーのみのRBF補間
4. SVGを3D Canvas の上にオーバーレイ
5. 顔の位置・サイズを3Dカメラから計算
6. ピッチ回転
