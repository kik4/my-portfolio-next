# 断面輪郭線ベース頭部モデリングツール - 企画書

## 背景と目的

アニメ・セルルックの3Dキャラクターは、角度によって「2Dの嘘」が必要になる。正面と横顔では頭部のシルエットが3D的に正しい形状とは異なり、アニメーターはそれぞれの角度で理想的な輪郭を描いている。

本ツールでは、ユーザーが角度ごとに頭部の**垂直断面の輪郭線**を描き、それらの断面からロフト的にメッシュを生成する。角度ごとの断面形状を変えることで、「2Dの嘘」を含んだ頭部モデルを構築する。

## 基本コンセプト

### 断面とは

輪郭線は「その角度から見たシルエット」ではなく、**その角度で頭部を垂直に切った断面の形状**である。

- 0°の断面: 正面で頭を前後に切った切り口（左右対称の輪郭）
- 90°の断面: 真横で頭を左右に切った切り口（鼻の出っ張り、後頭部の丸み等）
- 45°の断面: 斜め45°の平面で切った切り口

各断面は独立した2Dの閉じた曲線であり、その角度から見える外形（シルエット）ではない。例えば45°の断面には鼻の出っ張りは現れない（鼻は90°付近の断面で表現される）。

### ワークフロー

1. ユーザーが特定の角度を選択し、その角度の垂直断面の輪郭線を描く
2. プログラムが断面群を3D空間上に配置し、間を補間してメッシュを生成する（ロフト）
3. カメラ角度に応じて断面形状を変えれば、2Dの嘘を含んだモデルになる

## 機能

### 1. 断面エディタ

- 特定の角度を選択し、その角度の垂直断面の輪郭線を描画する
- 輪郭線はベジェ曲線または折れ線で制御点を配置する形式
- 制御点はドラッグで移動可能
- 輪郭線は閉じた曲線（断面の輪郭）
- 表示は正面から見た2Dビュー（Y軸が上下、描画面に垂直な方向が奥行き）

### 2. 角度キーフレーム

- 断面はカメラ水平角度に紐づく（0°=正面断面、90°=側面断面 など）
- 最低2つの角度（正面・横）があればメッシュ生成可能
- 角度を追加するほど中間の断面精度が上がる
- 中間角度の断面は隣接するキーフレームから線形補間

### 3. メッシュ生成（ロフト）

- 各角度の断面を3D空間上の対応する平面に配置する
  - 0°断面 → YZ平面上
  - 90°断面 → XY平面上
  - θ°断面 → Y軸を法線とする平面をθ°回転した面上
- 隣接する断面間の対応する頂点を結んで表面メッシュを生成する
- 各断面の頂点数は統一（例: 32頂点）
- 頂点の対応は上端（頭頂部）を基準に時計回りで自動対応

### 4. 3Dプレビュー

- 生成されたメッシュをリアルタイムに3Dビューで確認
- OrbitControlsでぐるぐる回して全角度を確認
- 自動回転モードで0°〜180°を往復
- 断面のワイヤーフレーム表示

### 5. データ管理

- 断面データのJSON出力・読み込み
- localStorage自動保存

## 技術スタック

- Three.js（3Dレンダリング・メッシュ生成）
- React + TypeScript（UI）
- Canvas 2D（断面エディタ）

## 最小構成（Phase 1）

1. 正面（0°）と横（90°）の2つの断面を描けるエディタ
2. 2つの断面からロフトでメッシュを生成
3. 3Dプレビューで確認

## 発展（Phase 2以降）

- 任意の角度のキーフレーム追加
- 断面間の補間カーブ調整（線形以外）
- 上下方向（垂直角度）の断面対応
- glTFエクスポート
- 目・眉のスプライト配置との統合

## 技術的な課題

- 各断面の頂点数を統一する必要がある
- 頂点の対応付けが重要（頭頂部を基準に時計回りで対応）
- 対応が悪いと中間角度でメッシュがねじれる
- 断面の形状が大きく異なる場合、補間結果が不自然になる可能性がある

## 方針

- まずはロフト方式で最小構成を実装する
- 断面は頂点数固定（例: 32頂点）の閉じた曲線
- 頂点の対応は上端（頭頂部）を基準に時計回りで自動対応
- 左右対称を前提とし、0°〜180°の半周分のみ扱う
