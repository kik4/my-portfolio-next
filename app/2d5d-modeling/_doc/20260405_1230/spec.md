# 2Dベジェ曲線ベース顔モデリングツール - 企画書

## 背景と目的

これまでの検証で、3Dメッシュに2Dの嘘を乗せる方法（ビルボードスプライト、断面ロフト）は構造的な限界があると判明した。

発想を転換し、**顔を完全に2Dで構築する**。顔はベジェ曲線を使った複数のパーツから成り、カメラ角度に応じて各曲線の制御点を移動・変形させることで、あたかも3Dのように見せる。Live2Dに近い発想。

髪だけは3Dメッシュとして構築する（シルエットのボリューム感と動きを出すため）。

## 基本コンセプト

### 2Dの顔

顔は以下のような独立したベジェ曲線パーツから構成される：

- 顔の輪郭線
- 左右の目（上まぶた・下まぶた・瞳・ハイライト）
- 左右の眉
- 鼻（鼻筋・鼻先）
- 口
- 陰影（頬のシャドウ、鼻筋のシャドウなど）

各パーツは2D空間上のベジェ曲線で表現される。

### 角度による変形

カメラ水平角度をパラメータに、各パーツのベジェ制御点を変形する。

- 0°（正面）では正面向きの顔
- 90°（横顔）では横顔の配置と形状
- 中間角度は補間

制御点の位置だけでなく、曲線の太さや色（陰影）も角度に応じて変えられる。

### 3Dの髪

髪だけは3Dメッシュ。これにより：
- 顔の輪郭の外側にシルエット（ボリューム）が出せる
- 髪の揺れや物理演算ができる
- カメラ角度で自然に見え方が変わる

顔（2D）と髪（3D）は同じスクリーン空間に重ねて描画する。

## ワークフロー

1. 特定の角度（0°、30°、45°、60°、90°など）を選択
2. その角度での各パーツのベジェ曲線を描画・編集
3. 複数の角度でキーフレームを作成
4. カメラ角度を動かすと、キーフレーム間を補間して曲線が変形
5. リアルタイムにプレビューで確認

## 機能

### 1. パーツエディタ

- 2Dキャンバス上でベジェ曲線の制御点をドラッグ編集
- パーツごとにレイヤー管理（輪郭、目、眉、鼻、口など）
- 各制御点は位置 + ハンドル（前後）
- 閉じた曲線・開いた曲線の両方をサポート

### 2. 角度キーフレーム

- カメラ水平角度に紐づくキーフレーム
- 各キーフレームで全パーツの制御点状態を保存
- 中間角度は制御点を線形補間

### 3. プレビュー

- 2Dキャンバスに現在の角度の顔を描画
- 3Dシーン上に髪のメッシュと重ねて表示
- OrbitControlsでカメラ角度を変更
- 自動回転モード

### 4. データ管理

- プロジェクトデータのJSON出力・読み込み
- localStorage自動保存

## 技術スタック

- React + TypeScript（UI・状態管理）
- SVG または Canvas 2D（ベジェ曲線の描画・編集）
- Three.js（3D髪メッシュ、角度制御、将来の拡張）

## 最小構成（Phase 1）

1. 単一パーツ（顔の輪郭のみ）のベジェ曲線エディタ
2. 2つの角度（0°と90°）でキーフレームを作成
3. 角度スライダーで制御点を補間して表示
4. 髪は後回し

## 発展（Phase 2以降）

- パーツの種類を増やす（目、眉、鼻、口、陰影）
- 3D髪メッシュの追加と顔との合成
- テクスチャ（塗り）のサポート
- 垂直角度にも対応
- アニメーション対応

## 技術的な課題

### ベジェ曲線の補間
- 制御点の対応付け（各キーフレームで同じ順序・同じ数の制御点）
- 補間方法（線形 / スプライン）
- 角度差が大きいときに自然に変形するか

### レイヤー順
- パーツの描画順（輪郭→陰影→目→眉...）
- 角度によっては描画順を変える必要があるか

### 顔と髪の合成
- 2D顔を3Dシーン上のどこに描画するか
  - HTML/SVGオーバーレイ
  - Canvas 2D + WebGLテクスチャ
  - Three.jsのplaneに2Dテクスチャを貼る
- 髪との前後関係（耳周りで髪が顔の上に来る等）

### パフォーマンス
- 多数のベジェ曲線を毎フレーム補間して描画するコスト
- 制御点数の上限を設ける

## 方針

- まずは最小構成（顔の輪郭 + 2角度補間）を作り、ベジェ曲線補間の手触りを確かめる
- 補間がうまく行くなら段階的にパーツを追加
- 2D描画はまずSVGで試す（制御点のドラッグ編集が容易）
