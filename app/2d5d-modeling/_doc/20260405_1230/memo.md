# 検証メモ

## 実装した内容
ベジェ曲線ベースの2D顔モデリングツール（Phase 1+α）。

### パーツ構成
- **顔の輪郭** (face-outline): シルエット統合、線あり
- **鼻** (nose): シルエット統合 + オーバーレイ、肌色の塗り、セグメントごとの線描画可能
- **左目 / 右目** (left-eye / right-eye): オーバーレイ、黒塗り

### 機能
- SVGベジェ曲線エディタ（アンカー・ハンドルをドラッグ編集、パス自体のドラッグで平行移動）
- 角度キーフレームによる補間（lerp）
- polygon-clippingによるシルエット統合（ユニオン）で鼻が顔の輪郭と繋がる
- 描画順 (z値) のキーフレーム補間で、回転中に目が顔の裏に回り込む表現が可能
- 各アンカーの `strokeNext` フラグで、一部のセグメントだけ線を描画（shift+クリックでトグル）
- `strokeNext` はキーフレームごとに保持、角度ちょうどで正しく反映される
- localStorage自動保存

### 鼻パーツの思想
1つのパーツで3つの役割を兼ねる:
- **正面**: 線なし、肌色の塗りが顔と同化
- **斜め顔**: 肌色の塗りで奥の目を部分的に隠す + 鼻筋の線を描く（strokeNextで設定）
- **横顔**: シルエット統合により顔の輪郭を拡張する

## 所感
- 顔が平面的な2Dとして扱える自由度の高さが良い
- シルエット統合 + オーバーレイ描画の組み合わせで表現の幅が広がる
- strokeNextによるセグメント単位の線描画切り替えは、正面と斜めで見た目を変える仕組みとして有効
- キーフレーム補間のスナップ動作（等しい角度の扱い）が直感的

## 次回試すアプローチ
- 眉、口、頬のシャドウなどの追加パーツ
- パーツの追加・削除機能
- テクスチャ的な表現（グラデーション等）
- 線のopacity補間で、角度に応じてフェードイン/アウトさせる表現
- 3D髪メッシュとの合成
- JSON入出力機能
